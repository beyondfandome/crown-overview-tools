# Crown Overview Tools v1.1.68

## Construction-per-round rule correction

- Players may start up to **3** building/upgrade projects per world round instead of only one per player.
- Each project must start in a **different province**: a province may start only one construction project in a given round.
- Each start still requires an available overseeing character and consumes/locks that character's strategic action for the round.
- A province may still have only one active construction project at a time, and newly transferred provinces remain blocked until the following round.
- Pending/offline-GM build requests follow the same three-per-player and one-per-province rules.
