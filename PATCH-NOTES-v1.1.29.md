# Crown Overview Tools v1.1.29

## Player-editable character details

The **My Characters / Move** dialog now includes an **Edit Details** button for every character controlled by the current player.

Players may edit roleplay/identity fields that Crown uses for diplomacy and character reference:

- Culture
- Religion / Faith
- Age
- Height / Weight
- Preferred Weapons
- Marriage / Spouse
- Issue / Children
- Public Notes

The module deliberately keeps the following GM-controlled:

- Character name / stable Character ID
- House affiliation
- Ownership / assigned player
- Location
- Primary and secondary mechanical stats
- Traits and quirks
- Status / visibility
- GM notes

Player edits are written to both the token and linked actor character/world-piece flags. Culture and Religion are mirrored onto the strategic piece so diplomacy sees the new values immediately.

Includes the v1.1.28 private action-chat fix and v1.1.27 political-overlay reliability fixes.
