# v1.2.02 — Tier 3 Influence hotfix

- Tier 3 Social buildings no longer provide recurring +3 Influence each collection.
- Award +3 Influence once at activation/completion, with a per-province durable claim marker.
- Tier 1 and Tier 2 recurring Influence income remains unchanged.
- Already completed Tier 3 buildings are not retroactively credited; this patch does not automatically claw back Influence previously overpaid.
- No changes to shared Gold/Food migration.
- Internal version, manifest version and release ZIP URL updated to 1.2.02.

**Test in a world backup before deployment.** The archive is syntax-tested but not live-Foundry-tested.
