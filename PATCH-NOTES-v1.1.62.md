# Crown Overview Tools v1.1.62

- The **Character** button in **My Characters / Move** now opens a read-only character sheet instead of only selecting the token.
- The sheet shows identity, location, primary stats, secondary stats, traits, quirks, marriage/children, and public notes.
- GMs additionally see GM Notes.
- A **Locate on Map** button preserves the old select/center behavior without making the sheet editable.
