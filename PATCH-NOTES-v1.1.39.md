# Crown Overview Tools v1.1.39

- Player building activity is no longer broadcast to the whole table. Build queued, construction/upgrade started, failed builds, and demolition messages are whispered to the acting player plus all GMs.
- GM-only build-processing/reset/repair summaries are whispered to GMs only.
- Diplomacy GM details now show an explicit final DC breakdown: base + defender Diplomacy + culture + religion + sworn loyalty.
- No diplomacy mechanics were changed in this release.
