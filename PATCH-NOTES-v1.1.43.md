# Crown Overview Tools v1.1.43

- Contested diplomacy keeps culture and religion modifiers signed: matching/related identities can reduce the defender total, while mismatches can increase it. No defensive clamp is applied.
- A province may have only one active construction project at a time. A second build/upgrade is blocked until the current project reaches its activation round.
- Political transfers now record the current world-round key in the ownership audit.
- Provinces that changed political control during the current round cannot start construction until the next round. This applies to diplomacy, marriage diplomacy, siege conquest, and other transfers that use the standard province-transfer path.
- Both the player Build dialog and GM-side build application enforce the new province construction locks.
