# v1.2.14 — My Characters action menu

- Replaced the separate Study, Recover, Apply Medicine, Diplomacy, Out-of-Map, Build and Siege buttons on each character row with one **Actions (Main Action)** button.
- Clicking Actions opens a choice dialog for that character and presents only currently usable actions; unavailable options are listed for clarity.
- Existing action handlers and the once-per-round Main Action enforcement are retained.
- Keeps Move Character, Army, Navy, details and GM controls on the character row.
- Updates displayed module version and GitHub release asset URL.

Requires a GitHub release tag `1.2.14` with the exact asset name `crown-overview-tools-v1.2.14.zip` for automatic updates. Not yet live-tested in Foundry.
