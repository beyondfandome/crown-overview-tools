# Crown Overview Tools v1.1.42

- Diplomatic Takeover becomes an opposed Diplomacy check when a character belonging to the controlling realm is physically present in the target province.
- Attacker: `d20 + Diplomacy (+ Marriage Diplomacy when applicable)`.
- Defender: `d20 + Diplomacy + culture modifier + religion modifier + sworn-loyalty modifier`.
- Ties favor the defender; the attacker must exceed the defensive total.
- A reactive defense roll does not consume the defender character's strategic action.
- If no controlling character is physically present, diplomacy uses the existing static province DC unchanged.
- Contested-result messages are whispered to both involved players and all GMs.
- GM details now identify whether the check was contested or static and show both rolls for contested checks.
