# Crown Overview Tools v1.1.66

Built directly from v1.1.65. The discarded broad Diplomacy-stat migration is not included.

## Diplomacy trait pass

Stored Diplomacy remains the character-sheet value (Statecraft / 4 plus permanent trait/quirk modifiers). Situational modifiers are now applied only when a Diplomacy check is resolved:

- Patriot: +3 vs same culture.
- Synchronist: -1 vs same culture; +3 vs another culture.
- Cultural Supremicist/Supremacist: +1 vs same culture; -3 vs another culture.
- Unorthodox/Unorthadox: ignores the normal different-culture diplomacy penalty (keeps the same-culture benefit).
- Valyraboo: -3 vs a non-Valyrian target.
- Blasphemer: -2 when the other side shares the character's faith.
- Dishonorable: -1 Diplomacy on all Diplomacy checks.
- Kinslayer defender: hostile Diplomacy against them gains +2.
- Bastard defender: hostile same-culture Diplomacy against them gains +2.

When a defending player character is physically present, their applicable situational Diplomacy modifiers are applied to the opposed roll as well. GM detail cards now show the situational modifier breakdown.
