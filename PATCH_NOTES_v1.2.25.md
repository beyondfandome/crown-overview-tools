# Crown Overview Tools v1.2.25 — GM Interception Logging

- Record all finished character interceptions in a persistent GM-only scene history (latest 300 entries), including automatically passed checks, defender-approved passage, blocked passages, and GM cancellations.
- Send a whispered Chat message to all GMs on resolution with character, province, defending army/lockdown, both contested roll totals (when applicable), outcome, and whether GM override was used.
- Add **GM: Interception Log** panel button showing pending requests and recent results; the existing **GM: Resolve Pending Interceptions** button still resolves pending cases.
- Results logging failures do not prevent passage decisions from resolving.
- All character interception constraints from v1.2.24 are retained, including once per character/province/round and unlimited different characters per defending army.

Requires live Foundry multiplayer testing. Existing interception events before this release cannot be reconstructed retroactively.
