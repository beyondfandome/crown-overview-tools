# Crown Overview Tools v1.1.72

- Adds explicit per-character **Main Action** tracking separate from movement.
- Replaces the old **Intrigue Action** button with **Out-of-Map Action (Main Action)**.
- Out-of-Map Actions can be Festival, Organize a Kidnapping, Hunt, Host a Feast, Religious Event, Research / Project, or Other, with freeform details for the GM.
- Out-of-Map Actions spend the Main Action but **do not spend or lock character movement**.
- Major-action UI now warns **This will take your Main Action** for Diplomacy, Siege/Storm, Build/Upgrade, Bank Loans, Diligent Prepare the Way, Army Muster, and Raids.
- Existing actions that ground a character continue to do so; Main Action tracking is now a separate lock so an Out-of-Map Action cannot be followed by another major action.
- Character turn screen now displays Main Action availability/reason separately from movement.
