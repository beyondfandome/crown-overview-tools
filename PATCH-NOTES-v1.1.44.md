# Crown Overview Tools v1.1.44

- Added **Take Intrigue Action** to the character turn menu. Committing it spends all remaining character movement and grounds the character until the next strategic round. Player requests are committed by the GM client.
- Starting a building/upgrade now grounds the overseeing character for the remainder of that round. This is only the opening construction round; later construction rounds do not keep the character grounded.
- Corrected construction duration to the intended slot-based rule from the Territories section of the guidebook:
  - Building slot 1: 1 round
  - Building slot 2: 1 round
  - Building slot 3: 2 rounds
  - Building slot 4: 2 rounds
- The Build dialog now displays the slot-based duration instead of using the building tier as the duration.
- Existing one-building-under-construction-per-tile and recently-conquered-tile restrictions remain in force.
