# Crown Overview Tools v0.3.4

Scene-gated strategic overview map tools for Crown of Ashes.

## Included in v0.3.4

- Fixes market-force scaling so changing a season from `1` to `0.5` halves all Gold/Food round income consistently.
- Market Forces now scale trade-goods income, development Gold/Food bonuses, manual base Gold/Food income, and building Gold/Food income.
- Removes the confusing separate hard-coded Winter half-scaling path so Winter behavior is controlled by Manage Market Forces.
- Keeps Gold-before-Food display order from v0.3.3.
- Keeps v0.3.2 manual base income clearing, trade goods, holdings, player vision, build queue, ownership, CSV import/export, and economy tools.
